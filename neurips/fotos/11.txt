### Sketch of the Summary

2. **Main contributions**: The paper presents three main contributions: (i) a provably optimal memory capacity for KHMs, (ii) the introduction of the U-Hop+ algorithm for achieving this capacity in sub-linear time, and (iii) a thorough numerical validation of the theoretical findings.

3. **Proposed technique**: The proposed technique involves treating stored memory patterns as a specialized spherical code and deriving necessary conditions for optimal memory capacity. The U-Hop+ algorithm is designed to maximize memory storage by optimizing the feature map used in KHMs.

4. **Main results**: The results demonstrate that KHMs can achieve optimal memory capacity when the memory set forms an optimal spherical code. The U-Hop+ algorithm significantly reduces metastable states and improves retrieval accuracy in both synthetic and real datasets.
